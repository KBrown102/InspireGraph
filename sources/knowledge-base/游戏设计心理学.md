游戏设计心理学的四套主干框架，回答的是同一件事：**玩家为什么会继续玩、玩的时候在感受什么**。定玩法前先过一遍，比凭感觉拍脑袋稳。

1. **MDA 框架**（Hunicke / LeBlanc / Zubek 2004）：美学 Aesthetics（玩家感受到什么——感官 / 幻想 / 叙事 / 挑战 / 情谊 / 发现 / 表达 / 消遣）← 动力学 Dynamics（玩出来的涌现行为）← 机制 Mechanics（我们写的规则）。**要倒着设计**：先定"玩家该有什么感觉"，再反推会涌现什么行为，最后才定规则。
2. **自我决定理论 SDT**（Deci & Ryan）：三个基本心理需求——**自主性**（有意义的选择，杜绝假选择和唯一最优解）、**胜任感**（看得见的成长，且玩家必须知道成败原因）、**关联感**（与角色 / 世界 / 他人的连接；单机也能靠 NPC、宠物、叙事羁绊满足）。
3. **心流通道**（Csikszentmihalyi）：难度与能力匹配，卡在焦虑与无聊之间的窄带。能力涨了难度必须跟着涨。
4. **锯齿难度曲线**：张力沿一段序列爬升 → 在里程碑释放 → 回到更高基线重新咬合。忌平线（无聊），忌垂直尖峰（挫败）。
5. **脚手架挑战**：新机制先孤立引入再组合；前十分钟靠玩学会，不靠教程文本。
6. **微反馈 0.5 秒**：任何操作 0.5 秒内必须有可读后果；战略级反馈落在中循环（5–15 分钟）。
7. **失败恢复成本与失败频率成正比**：高频失败（战死）要秒恢复；低频失败（boss）可以给中等代价。
8. **Bartle 玩家类型**：**成就者**（要进度 / 收集 / 可量化里程碑）、**探索者**（要隐藏内容 / 系统深度 / 知识即力量）、**社交者**（要共处空间 / 共同目标 / 身份表达）、**竞争者**（要公平对抗 / 技术可见 / 有意义的赌注）。
9. **Quantic Foundry 六维**（比 Bartle 细）：动作（破坏 / 刺激）、社交（竞争 / 社群）、精通（挑战 / 策略）、成就（完成 / 力量）、沉浸（幻想 / 故事）、创造（设计 / 发现）。
10. **玩家幻想 Player Fantasy**：写设计前先写一句"玩家在这个机制里感觉自己是谁"。说不清这句，机制多半是空的。

设计启示（接我们项目）：
- **每日小游戏（治愈 / 回血向）**：主打自主性 + 关联感，弱化胜任感压力；MDA 锚定「消遣 / 表达 / 发现」；心流走低位平缓锯齿（不制造焦虑）；失败恢复成本压到接近零；避开显性策略。
- **直播互动（巴别塔）**：主打胜任感 + 竞争者；MDA 锚定「挑战 / 情谊」；微反馈要快狠（< 0.3 秒，观众看得见）；失败必须秒恢复，不能让人掉线等。
- **沙盒类（蚁界）**：主打自主性 + 探索者；MDA 锚定「发现 / 幻想 / 表达」；心流不靠关卡曲线，靠系统涌现与自我设定目标。
- **通用自检**：这个机制满足了三个心理需求里的哪一个？玩家 0.5 秒内能感知到什么？难度是在爬升还是在原地打转？
