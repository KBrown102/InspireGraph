抖音「油菜菜」，石塑粘土手作博主，6.1 万粉 / 55 万赞 / 30+ 作品。抓取分析了她最新 19 条作品文案（2026-08-01）。
她的东西之所以好看，不在于捏得多精细——**在于她给每个物件配了一句让它活过来的话，和一个让手指想去动它的机关**。这两点可以整条搬进小游戏。

---

## 一、文案叙事法（最值钱的部分）

她几乎不写"今天做了个小猫"，每条都是一句自带世界观的短句。归纳出 5 种可复用句式：

| 句式 | 原句 | 机理 |
|---|---|---|
| **童谣祈愿** | 小鱼小鱼快快游，四面八方皆自由 | 叠词呼唤 + 祝福落点。像哄小孩，也像哄自己 |
| **超现实童话** | 小猫的世界下起了小鱼雨 | 把欲望具象成天气。因果反转：猫爱吃鱼 → 那就让天上下鱼 |
| **伪常识断言** | **众所周知！** 行李箱里是会长出小猫咪的 | 用"众所周知"给荒诞盖章，读者会心一笑，比解释更有效 |
| **禅意重言** | 拥有苹果时，只在意苹果 | 同词复现的禅宗句法（吃饭时吃饭）。物件立刻有了哲思 |
| **温柔祝愿** | 希望你漂亮的眼睛只流幸福的泪 | 直接对着看的人说话，把作品变成礼物 |

**共同点**：主语永远是被造出来的那个小东西，不是创作者。她从不说"我做了"，只说"它怎么了"。
→ 迁移：游戏文案也该让物件自己说话，别让旁白解释规则。（与「literary-copywriting 非引导式叙事」纪律完全同源）

## 二、机关结构（对游戏交互最直接的启发）

她的爆款几乎都不是"静态摆件"，而是**能被手指动一下的东西**：

- **可换配件**：可换帽子的小猫挂件 → 一个基座 + N 个可替换部件 = 装扮 / 收集 / 图鉴
- **抽拉机关**：可抽拉小猫对联冰箱贴 → 拉动才揭示第二层内容，"拉"这个动作本身即快感
- **掉落惊喜**：镜子改造，打开时掉落蛋糕 → 触发式彩蛋，惊喜藏在"打开"这一帧
- **功能伪装**：泡澡的噜噜其实是香薰炉 → 看着是装饰，用起来有实际功能，一物两重身份
- **微缩场景**：夏日云朵泳池 → 巴掌大的一个完整世界，可俯视、可窥探
- **容器孕育**：行李箱里长出小猫 → 封闭容器打开后有生命，"开箱"结构

→ 这六种全是**一次交互 = 一次情绪回报**的结构，正好对应爽感脑区的"收集 / 抽卡 / 合成"。抽拉和开箱本质就是低配版抽卡（延迟揭示 + 变率奖励）。

## 三、意象母题

小猫（出现 8 次，绝对主角）· 小鱼（4 次）· 苹果（3 次）· 云朵 · 星光 · 汤圆 · 泡澡。
**清一色是"能被捧在手心的尺寸"**——没有宏大意象。治愈感的来源之一就是尺度：小到可以被保护。

## 四、内容节奏（运营层，做游戏也用得上）

- **节令绑定**：元宵汤圆 / 春节对联 / 圣诞苹果 / 毕业礼物 / 年终总结 —— 同一套技法跟着日历换皮，稳定产出不枯竭
- **教程与作品交替**：作品秀审美，教程降门槛。《低成本入坑材料分享》是典型的"扩大池子"内容
- **过程可见**：捏塑类内容天然有"从一团泥到成型"的弧线，这个弧线本身就是观众要看的东西

→ 迁移：每日小游戏也可以做「节令轮转」——同一玩法内核，跟着节气换意象（这比每天想新机制可持续得多）。
→ 「过程可见」是治愈玩法的通用配方：让玩家看见东西在自己手里一点点变成形。

## 五、可直接长成游戏的三个种子

1. **捏塑成型**：Canvas 上一团可推可拉的软泥，跟着轮廓引导捏出小猫/小鱼。核心快感是"手感"与"渐渐像了"。配「过程可见」+「可换配件」做装扮收集。
2. **小鱼雨**：超现实童话直译成玩法——点击让天空落下小鱼，猫在下面接。荒诞而温柔，无输赢。
3. **开箱孕育**：一个个封闭容器（行李箱/贝壳/礼盒），拖动打开，里面长出不同的小东西，集齐图鉴。抽拉 + 开箱 + 收集三合一。

## 六、一句话内核

**她做的不是手工，是"给一件小东西编一个它值得被爱的理由"。**
物件 + 一句让它活过来的话 + 一个能动的机关 —— 这三件套，就是治愈系内容的最小完整单元。
