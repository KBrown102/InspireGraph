# 创作者观察 · 中国传统色配色库

> 来源：抖音「杨大小姐Eva」2026-07-23 视频《反对西方色彩霸权，重新定义中国传统色审美》
> 落库日期：2026-08-09 ｜ 用途：审美脑区配色参考 + 游戏视觉 mod 文化锚点

## 核心观点

中国传统色**每一色背后都有文化故事与情感内涵**，不是工业化的色号。西方品牌（爱马仕/Tiffany/香奈儿等）通过注册私有色 + 营销话术，重新定义了我们的审美认知；但中国传统色本来就有高级感，不需要被西方定义。

每一个中国色都是：**自然的恩赐 + 历史的沉淀 + 文化的载体 + 信仰的表达**。

## 设计启示（游戏视觉 mod 可用）

1. **单色叙事升级**：和 HIROSTOPTIME 的「一种颜色统治一张图」互补——中国色提供**有文化重量的主色**，不再是纯视觉绿/粉，而是「桃夭粉」「群青蓝」这种带故事的色。
2. **配色规则**：一个作品 = 一个主色（中国色）+ 一个补色（小范围）+ 大量同色系延伸。主色覆盖率 ≥ 60%。
3. **情感锚点**：配色不只是好看，还能**承载叙事**——朱殷用于悲壮牺牲桥段、群青用于神圣/永恒场景、玄色用于天地初开/混沌母题。
4. **反向创新**：可以故意用「西方品牌色」做反差——比如用玄色对抗香奈儿黑，做「东方高级感」主题关卡。
