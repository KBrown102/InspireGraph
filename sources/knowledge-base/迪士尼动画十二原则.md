迪士尼动画十二原则出自 Ollie Johnston & Frank Thomas《The Illusion of Life》(1981)，原本总结手绘动画如何让运动有生命。但它不是手绘专属，而是一条「让运动看起来有重量、有意图、有生命」的通用法则，同样适用于我们用代码做动效（CSS / JS / Canvas / WebGL / 微交互 / 游戏反馈）。

1. **挤压与拉伸**：物体变形表达柔韧与质量，但视觉体积守恒；代码里用 `scale` 双向补偿 + 弹性曲线。
2. **预备动作**：主动作前的反向蓄力（下蹲、收肩），让观众预判；代码里入场前反向预位移一帧。
3. **演出布局**：一个画面只讲清一件事，用构图/灯光/镜头引导视线；代码里靠层级、聚焦、遮罩、模糊压暗非重点。
4. **连贯动作 vs 姿态对应**：逐帧顺画（自然随机）vs 先关键帧再补间（可控）；代码里结构用 Pose to Pose（@keyframes / RAF 插值），细节用 Straight Ahead（粒子模拟）。
5. **跟随与重叠**：主体停下附属物还在动，部件不同步；代码里用拖尾、stagger、末端衰减摆动。
6. **缓入缓出**：起止加帧自然加减速；代码里默认不用 linear，用 ease-in-out / cubic-bezier。
7. **弧线运动**：自然运动走弧线非直线；代码里位移走贝塞尔/极坐标，叠加正弦扰动。
8. **次要动作**：辅助动作添层次不抢戏；代码里主反馈外叠呼吸缩放、光晕，幅度更小且错峰。
9. **时间节奏**：帧数决定重量/速度/情绪；代码里 duration 即重量，重物体更慢，命中用定格+回弹做打击感。
10. **夸张**：基于真实但强化关键；代码里 overshoot 过冲、三连反馈，幅度克制可调。
11. **立体造型**：即使 2D 也要有体积/重量/平衡；代码里用投影、高光、伪 3D 倾斜。
12. **吸引力**：角色/画面简洁有辨识度、讨人喜欢；代码里圆润形态、留白、克制配色、风格一致。

设计启示（接我们项目）：
- 通用动效底线：默认缓动（非 linear）、scale 形变体积守恒、一画面强动效 ≤ 2、移动必带拖尾/次级、自然运动走弧线。
- 治愈 / 回血向（每日小游戏、蚁界）：强化吸引力 + 缓动 + 次要动作，动效温柔有呼吸；克制夸张幅度避免焦虑。
- 直播互动 / 巴别塔：强化时间节奏 + 预备动作 + 夸张，反馈要快狠记得住，命中用定格+回弹+发光做打击感。
- 代码落地资源：缓动抄 easings.net 的 cubic-bezier，弹性用 CSS 回弹曲线或 framer-motion / Popmotion，拖尾用 Canvas 历史坐标或 WebGL 点系统。
