抖音「HIROSTOPTIME」（又名「居酱子爱拍照」「那一抹绿」），人像摄影师。本笔记基于用户下载的 99 张合集中**逐张实际看过的 12 张样本**（IMG_5433、IMG_5448、IMG_5482、IMG_5486、IMG_5488、IMG_5504、IMG_5505、IMG_5506、IMG_5507、IMG_5514、IMG_5519、IMG_5529），其余 87 张**未实际看过**，仅作后续验证用。

她的东西之所以让人想盯着看，**不在于拍得多清晰，在于整张图被一种"颜色"统治了**——颜色不是配的，是全部浸进去的。这个手法可以整条搬进小游戏做视觉 mod。

---

## 一、拍摄风格（镜头语言）

### 1. 单色叙事 + 一致性人设

- **同一个少女模特反复出镜**（白金/金假发 + 各种彩色假发 + 二次元美瞳 + 夸张腮红 + 嘴角痣）
- 每组作品围绕一个**主色**展开：服装 + 假发 + 背景 + 道具 + 妆面 + 后期色调**全部统一在同色系**
- 形成极强的视觉签名："HIROSTOPTIME = 那抹绿 / 那抹粉 / 那抹蓝 / 那抹黄"
- 12 张样本里能看到至少 6 套色（绿/红/紫/黄/蓝/粉）—— 同一张脸换了 6 种颜色就成了 6 个作品

### 2. 场景诗化（超现实日常）

- 把日常物品摆到不日常的位置，制造梦境感：
  - **钢琴入水**（IMG_5433）：一架白色立式钢琴放在粉调花海倒影的水里
  - **救生圈当画框**（IMG_5505）：红白救生圈套在少女身上，背景红白条纹墙
  - **汽车旁摔倒**（IMG_5506）：少女躺倒在紫色跑车旁，浑身紫色道具散落
  - **绿叶包围**（IMG_5504）：植物从画面四周把脸"框"起来
  - **水中跃起**（IMG_5519）：少女从水池里挥手扬水花，周围全是星形光斑

### 3. 夸张动作 / 大开大合

- 拒绝静态摆拍：**仰头大笑、扬手洒花瓣、向天空伸手、躺在地上、跃出水花**
- 人物永远在做"大动作"，情绪永远在脸上

### 4. 自然光为主

- 户外场景占绝大多数，依赖阳光 + 散射光
- 逆光（IMG_5514 绿树林那张最典型，从树冠洒下）+ 暖光（IMG_5529 银杏）+ 柔光（IMG_5486 海边）

## 二、修图技巧（后期核心手法）

### 1. 单色 Color Grading（最核心）

- **整张图压向一个主色调**：绿图里皮肤偏粉绿、粉图里皮肤偏粉红、紫图里皮肤偏冷紫
- 让所有元素统一在"色彩调性"里，像整张图被那颜色浸过一遍
- **这是她和普通摄影师最大的区别**：普通摄影师只在背景/服装上做配色，她是连皮肤、连高光阴影都染色

### 2. 柔光磨皮 + 油画滤镜

- 整体高斯柔焦，边缘虚化（IMG_5529 银杏、IMG_5514 树林、IMG_5448 花海那几张尤其明显）
- 后期叠加**油画/水彩笔触滤镜**，把照片往绘画感推
- 面部磨皮非常重，但保留眼睛、嘴角痣、假睫毛的细节

### 3. 闪耀特效叠加（Bling/光斑）

- **多次出现**：四角星形光斑、彩虹光晕、bokeh 光斑、bling
- IMG_5519（水中跃起那张）光斑最密集，几乎每个水珠都是星形
- 这些**不是拍出来的，是后期叠加的光效素材**——叠了非常多层

### 4. 颗粒 / 胶片感

- 整体有低强度的颗粒/胶片噪点
- 避免数字感太干净，让画面"有手温"

### 5. HDR 柔化（梦幻过度曝光）

- 暗部大幅提亮、高光压平，整张图亮度均匀
- 视觉上像被柔光镜/黑丁丁黑柔滤镜罩过

### 6. 飘落元素叠加

- **大量后期添加飘落素材**：樱花瓣、玫瑰花瓣、银杏叶、羽毛、花瓣
- IMG_5482（粉发少女在城堡前）那张漫天飞粉色花瓣
- 创造"时间静止但仍在流动"的动态感

### 7. 水印

- 每张右下角都有"抖音号：HIROSTOPTIME"
- 偶尔出现 "OPPO Find X9 Pro" 设备水印（应该是手机拍摄的直接水印，没特意去）
- 水印字号小、不喧宾夺主

## 三、配色（核心母题色板）

按 12 张样本中的出现频率排序：

| 主色 | 视觉关键词 | 样本 |
|---|---|---|
| 🟢 **绿色** | 那爱绿 / 焦绿 / 集装箱绿 / 草绿 | IMG_5488（集装箱+床单幽灵）、IMG_5504（绿叶包围）、IMG_5507（绿草地）、IMG_5514（绿树林） |
| 🌸 **粉色** | 梦幻粉 / 樱花 / 玫瑰 | IMG_5433（粉调钢琴入水）、IMG_5482（粉发+城堡+玫瑰） |
| 🌊 **蓝色** | 蓝调 / 海 / 水 | IMG_5486（蓝色海边长裙）、IMG_5519（水中跃起） |
| 🍂 **黄色** | 芒果黄 / 银杏 / 向日葵 | IMG_5529（银杏黄叶+向日葵） |
| ❤️ **红色** | 生命红 / 救生圈 / 玫瑰 | IMG_5505（红救生圈+红裙） |
| 💜 **紫色** | 霜紫 / 跑车 / 紫衣 | IMG_5506（紫跑车+紫衣） |
| ⚪ **白色** | 留白 / 婚纱白 | IMG_5448（白裙少女背影+白色花束） |

### 配色逻辑（可直接复用为游戏配色规则）

1. **一个作品 = 一个主色 + 一个补色 + 大量同色系延伸**
2. **主色覆盖率 ≥ 60%**——背景/服装/假发/道具/妆面/后期色调全部同色
3. **补色只在小范围出现**（红救生圈 + 红白条纹、粉玫瑰 + 蓝色天空、白花束 + 彩色花海）
4. **同一色系内的深浅变化**（浅黄嫩叶 → 深黄老叶 + 黄色毛衣裙 + 金色假发）
5. **撞色 = 主色 + 白/黑**（红 + 白条纹、蓝 + 白纱裙、绿 + 白皮肤）
6. **饱和度统一**：所有色块饱和度相近，没有"突兀的鲜艳"或"突兀的灰"

## 四、构图（画面骨架）

### 1. 中心 + 黄金位

- 人物永远在画面**中心或黄金分割交点**
- 视线/动作引导到画面正中

### 2. 框景 + 前景遮挡

- 用道具做画框：救生圈（IMG_5505）、植物（IMG_5504）、花瓣虚化（IMG_5482）
- 多层次前中后景，**画面纵深强**

### 3. 夸张互动

- 人物永远在做"大动作"：仰头笑、扔花瓣、伸手、摔倒在地、跃出水花
- **拒绝静坐、拒绝"美美地看着镜头"**

### 4. 留白铺陈

- 背景天/海/草地占画面 60%+
- 给主色调提供"延展空间"，不挤

### 5. 三种尺幅交替

- **特写**：IMG_5504 绿叶包围那张（脸部 + 绿叶填满画面）
- **中景**：多数样本
- **全景**：小人在大场景中（IMG_5514 树林、IMG_5529 银杏）

### 6. 开放式构图

- 人物身体/视线经常被画框边缘切掉
  - IMG_5529 银杏那组脚部在画外
  - IMG_5514 树林那组头顶被切
- 不追求完整人物，更追求氛围

### 7. 物品 + 人设互文

- 道具不是装饰而是**叙事**：
  - 救生圈 = 束缚/保护
  - 钢琴 = 诗意/日常物品入画
  - 花束 = 情绪出口
  - 墨镜 = 时尚符号
  - 银杏叶 = 秋天/时间流逝

## 五、一句话内核

**她拍的不是照片，是"用一种颜色统治一整张图"。**

人设一致 + 场景诗化 + 单色 color grading + 油画滤镜 + 闪耀光斑 + 飘落花瓣 —— 这六件套，就是 HIROSTOPTIME 视觉签名的最小完整单元。

---

## 六、可直接长成游戏视觉 mod 的配方

1. **"单色浸染"关卡 mod**：每关选一个主色，把所有元素（场景/角色/UI/特效）压向那个色调，玩家每次进入就是不同的色彩世界。
2. **"物品入画"叙事**：日常物品（钢琴、救生圈、家具）放到不日常位置（水中、悬浮、倒置），做超现实场景。
3. **"夸张动作"反馈**：NPC/角色永远在做"大动作"，不静止摆 pose——失败时仰头笑、胜利时躺倒在地。
4. **"飘落元素"沉浸**：背景永远有飘落素材（花瓣/叶子/羽毛），关卡里增加粒子层级。
5. **"闪耀特效"反馈**：每次成功/收集动作触发星形光斑+彩虹光晕，把"爽"用视觉重锤一下。
6. **"框景+前景虚化"关卡构图**：用前景道具做画框，3D 场景的景深做出"透过花瓣看主角"的层次。
