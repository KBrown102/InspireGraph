# 视觉技术：辉光 / 星云团效果

> 来源：诗云 shiyun.cohenjikan.com（独立开发者 Cohenjikan 的开源项目，技术栈 Vite + React + TS + three.js / react-three-fiber + postprocessing）+ 本仓库 `neuron-3d.js` 前端的「假 bloom」实现。
> 归类：视觉技术搭配（非单一风格，而是一套可复用的发光表现手法）。已同步入神经元系统 `taste.json`（辉光后期 / 加色混合 / 星云团观感）与技能树 `Claw/references/tech/bloom-glow/`。

## 一、诗云是怎么做的（真 bloom 路径）

把 33,458 位诗人、97 万首诗映射为三维螺旋星系：诗人=发光星、诗=坐标、虚空=「一切可能的诗」（致敬刘慈欣《诗云》+ 博尔赫斯《巴别图书馆》）。

星云团观感来自四件套：

1. **Bloom 辉光后期**（postprocessing / UnrealBloomPass）——亮部外溢模糊并叠加回画面，星点「炸」出光晕。
2. **加色混合（Additive Blending）**——重叠处亮度相加而非覆盖，密集区自然融成发光团。
3. **按类别分色成团**——同一类（朝代/诗人）用同色，空间上聚成一簇发光星云。
4. **缓慢自转**——`autoRotate` 给「活的宇宙」呼吸感。

## 二、我们的实现（零依赖假 bloom）

本仓库 `neuron-3d.js` 是 Three.js r128 本地 UMD、**离线、没有 postprocessing 模块**，拉不到真 UnrealBloomPass。改用「假 bloom」：

- **神经元辉光层 `_createGlowPoints`**：在已有锐利星核 `Points` 之外叠一层更大尺寸的纯径向柔晕 `Points`（exp 衰减 shader + 加色混合）。尺寸由权重驱动（`uGlowBase=16` → `uMaxGlow=42`）。
- **脑区发光团 `_createRegionHalos`**：按每个脑区神经元实际质心放一团大号柔光 `Sprite`（径向渐变 canvas 纹理 + 区域色 + 低透明 `opacity=0.08` + 加色混合），「审美 / 爽感 / 开发」读成发光星云团。
- **自动旋转**：`controls.autoRotate=true`（默认开），UI 可切。
- **辉光开关**：`setGlowEnabled(on)` 同时切换 `glowPoints.visible` 与所有 `regionHalos.visible`，UI 按钮默认高亮。

> 技术结论：真 bloom 观感 ≈ 假 bloom（柔晕 Points + 区域光晕 Sprite + 加色混合），且零新依赖、离线可用。**做小游戏首选假 bloom**，除非你已引入 postprocessing 链路。

## 三、技术搭配三件套（给灵感链路用的颗粒）

| 技术 | 一句话 | 在神经元库的落点 |
|------|--------|------------------|
| 辉光后期（bloom） | 亮部外溢模糊叠加，节点「点亮」 | `taste:bloom`（审美） |
| 加色混合（additive） | 重叠加亮，密集区融成发光团 | `taste:additive`（审美） |
| 星云团观感（region halo） | 同类分色成簇、区域柔光晕 | `taste:nebula`（审美） |

三者关系：**加色混合是底层机理 → 辉光后期是单点的表现 → 星云团是群体的成簇表现**。

## 四、小游戏怎么用这套

- **节点/单位发光**：角色、能量、收集物用 bloom 提亮，立刻「活」起来（治愈系必备）。
- **能量丝 / 连线**：突触线加 bloom + 加色混合 → 数据流/神经脉冲观感（参考本仓库突触线）。
- **背景星点簇**：远处撒低权重发光点 + 加色混合 → 宇宙/梦境底。
- **UI 辉光**：按钮、选中态、进度环叠 bloom 光晕（与 `taste:liquid_glass` 液态玻璃同属「现代光感 UI」）。

## 五、配色搭配（接已有审美基因）

- **单色叙事（HIROSTOPTIME）**：整屏统一主色 + bloom，辉光也染成同色 → 最克制最统一（参考 `taste:style_hiro` + `taste:monochrome`）。
- **中国传统色**：群青（神性蓝）做星空辉光、玄色（极黑）做背景吞噬、朱殷（深红）做危险脉冲 → 文化锚点 + 发光（参考 `taste:color_qunqing` / `color_xuan` / `color_zhuyin`）。
- **印象派**：莫奈睡莲池的浮光 + bloom = 水中光斑（参考 `taste:impressionist` / `taste:monet`）。

## 六、坑（踩过 & 预判）

1. **节点多时过曝**：全图叠加色混合 + 区域光晕，密集脑区会糊成白团。**解法 = 辉光开关**（本仓库已加，默认开、可一键关掉看结构）；或下调 `glowPoints` 的 `alpha` 系数与 `uMaxGlow`、区域光晕 `opacity` 降到 0.05。
2. **真 bloom 离线拉不到**：postprocessing 是 examples 模块，本地 UMD 不带；强引会崩。**离线项目一律用假 bloom**。
3. **性能**：辉光层是额外一遍 Points 渲染，千级节点无压力；若到万级，考虑只对激活/悬停节点画辉光（按需显隐）。
4. **不要丢本体身份**：纯星云（螺旋星系 + 穷举哲学）适合诗云，但咱们是「模仿大脑」——保留离散神经元 + 突触连线，辉光只是叠加表现，不喧宾夺主。
