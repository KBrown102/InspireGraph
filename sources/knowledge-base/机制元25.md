所有游戏玩法拆到底层其实都只是在做五件事：建立、撤销、改写、转流、重构；这五种变化又可拆成二十五个机制元。设计复杂玩法时，先选变化方式，再回表查具体动作组合即可。

## 一、建立（让事物出现 / 落位 / 关系 / 信息 / 权限）
1. 生成：让对象出现
2. 放置：让对象落位
3. 连接：建立关系
4. 揭示：公开信息
5. 解锁：开放权限

## 二、撤销（删除 / 切断 / 花掉 / 收起 / 关闭）
6. 移除：删除对象
7. 断开：切断关系
8. 消耗：花掉资源
9. 隐藏：收起信息
10. 锁定：关闭权限

## 三、改写（换身份 / 位置 / 方向 / 数值 / 操作人 / 时间）
11. 替换：换掉身份
12. 位移：改变位置
13. 旋转：改变方向
14. 标量调整：改变数值
15. 控制权转移：换人操作
16. 延迟执行：把结果推到以后

## 四、转流（一起动 / 变身 / 拆分 / 探知 / 概率 / 主动）
17. 耦合位移：一起移动
18. 转化：变成别的东西
19. 分配：拆开资源
20. 侦测：取得答案
21. 随机选择：交给概率
22. 行动者选择：主动决定

## 五、重构（合 / 换 / 拆）
23. 合并：多个变成一个
24. 置换：交换位置
25. 拆分：一个变成多个

设计启示（接每日小游戏 / 蚁界 / 巴别塔）：
- 一个「复杂玩法」= 从 5 类里选若干变化 + 用 25 元做具体动作组合。不用死记 25 词，先定「这关要让玩家经历哪种变化」，再回表挑动作。
- 与「游戏循环 13 方向」互补：13 方向管玩家**为何持续玩**（动力循环），25 机制元管**玩法动作如何被组装**（原子操作）。做游戏时先定循环方向，再选机制元拼具体交互。
- 治愈向慎用纯「消耗 / 锁定 / 移除」的高压组合，可偏「生成 / 揭示 / 解锁 / 合并」的正向反馈。
- 蚁界沙盒里「生成 / 放置 / 连接 / 消耗 / 转化 / 拆分」天然是蚁群模拟的底层动作，这套表可直接当系统建模词典。
