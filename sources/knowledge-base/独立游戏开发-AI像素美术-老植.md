# 独立游戏开发 · AI 像素美术落地（老植案例）

> 来源：抖音「老植」2026-03-20 视频《一分钟学会制作独立游戏像素角色》
> 落库日期：2026-08-09 ｜ 用途：像素美术风格基因 + 7 步工作流 + 技能树美术分支 pixel-art/

## 解决的核心痛点

> **AI 生成的美术图无法落地使用** —— 0 美术基础的独立游戏开发者（策划、程序）也能用。

无需 PS 基础，0 美术上手即用。

## 工具：Lovart 平台（推荐 Nano Banana Pro 模型）

## 7 步标准流程（角色制作）

1. **八方图制作**：4 方向行走 + 4 方向攻击。参考设定：战士、白发、红眼、龙纹盔甲、红围巾、红金配色
2. **风格转换**：Nano Banana Pro 模型，限制 64×64 / 32 色 / 像素赛璐珞边
3. **精灵图制作**：6 连击帧（挥→刺→收）
4. **透明底背景处理**
5. **文字编辑**：游戏场景图、UI 文字
6. **元素编辑**：局部修改，不用切软件
7. **PSD 文件导出**（关键）：AI 出图 → PSD 分层 → 人工微调

## 额外应用

- 拼豆图纸
- 覆盖角色 / 场景 / 道具 / 技能特效全美术内容

## 像素艺术风格基因（视觉 mod 描述，非侵权提示词）

- **16-bit retro RPG pixel**（如 Earthbound / 地球冒险）
- **Eastward 像素风**（风来之国，暖色调叙事像素）
- **chunky blocky pixel art**（粗块像素，roguelike 独立游戏 sprite 主流）
- 限制：低分辨率（32/64px）、有限色板（16-32 色）、硬边轮廓、平涂无渐变

## 对神经元系统的价值

- **审美脑区**（taste.json）：HD-2D 像素风 / 像素美术（chunky blocky）
- **技能树美术分支**：`Claw/references/styles/pixel-art/SKILL.md`（7 步流程 + 风格基因）
- **灵感链路**：题材 → 玩法（roguelike）→ 画风（chunky 像素）→ 配色（朱殷/玄色）
