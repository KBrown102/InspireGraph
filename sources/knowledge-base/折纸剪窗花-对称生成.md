把"折纸裁剪"做成治愈小游戏的核心洞察：**折叠 = 几何对称群**。一张红纸折成 N 层（如 12 层 = 12 重旋转对称），玩家只在 30° 楔形小角上划几刀，展开后系统把这一角旋转复制 N 份并镜像翻面，得到一张对称而独一无二的窗花。已落地为一款治愈系折纸小游戏。

## 可复用的实现技术（前端 Canvas）
- **对称生成**：离屏 canvas 把楔形图案旋转复制 N 份（每份 360/N°），奇数份镜像翻转，拼成完整图案。对称是数学免费送的审美兜底，所以随手套几刀都好看——适合作为"低美术门槛也能出彩"的玩法基底。
- **镂空（destination-out）**：剪痕用 `globalCompositeOperation='destination-out'` 擦除红纸、露出底光，而非画白线——这才是真正的透光镂空。
- **极坐标归一化存储**：剪痕不存像素，存 `(rr, th)`——rr 是离圆心相对半径(0~1)、th 是角度。与屏幕分辨率彻底脱钩，窗口缩放后重画不歪、已生成图案可无损重生成（resize 重绘的底气）。
- **扇形 clip 旋开动画**：用 `clip` 把图案裁成扇形，再逐步展开到 360°，模拟纸展开的过程。

## 治愈交互设计（游戏实验场铁律：治愈≠空无）
- 可操作动词：剪 / 展开 / 贴窗（三段清晰弧线）。
- 即时柔和反馈：纸屑粒子簌簌落、咔嚓轻响、贴窗暖光涟漪。
- 缓慢变化弧线：贴满 N 格屋子渐暖、夜色转晨光。
- **故意不做撤销**：每一刀都写进归一化剪痕数组、不可反悔，歪掉的那一刀反而成了最好看的地方——把"不可逆"变成情感设计点。

## 思想内核
对称给秩序，你的不确定给灵魂；同一个模板，长出没有重样的生命。适用于"允许自己和别人不一样 / 不必活成模板 / 接纳不完美"类心理需求。

## 可迁移方向
- 雪花 / 万花筒 / 民族纹样 / 曼陀罗对称图案，都是同一引擎换皮肤。
- "折叠即对称"可泛化：任何"局部操作 → 全局对称映射"的玩法（如折扇、折纸船、对称拼贴）。
